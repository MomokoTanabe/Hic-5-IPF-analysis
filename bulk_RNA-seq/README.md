# Bulk RNA-seq Analysis of IPF Fibroblasts Treated with siHic-5

## Overview

This repository contains R scripts for the analysis of bulk RNA-seq data from idiopathic pulmonary fibrosis (IPF) fibroblasts treated with siHic-5.

The analyses include:
- Heatmap visualization of highly variable genes
- Gene Ontology Cellular Component (GO-CC) enrichment analysis
- Gene Set Enrichment Analysis (GSEA) of TGF-beta signaling, epithelial-mesenchymal transition (EMT), and extracellular matrix (ECM)-related pathways

## Dataset

The RNA-seq dataset is available from the Gene Expression Omnibus (GEO):

- **GEO accession:** GSE248253

The analyzed samples correspond to the following experimental conditions:

| Sample | Condition |
|---|---|
| mock | Mock control |
| TGFB1_mock | TGF-beta1 stimulation |
| TGFB1_siCNT | TGF-beta1 stimulation with control siRNA |
| TGFB1_siHic-5 | TGF-beta1 stimulation with Hic-5-targeting siRNA |

## RNA-seq Data Processing

Raw sequencing reads were processed before the R-based analyses.

The preprocessing workflow consisted of:

1. Quality assessment of FASTQ files using FastQC.
2. Alignment to the human reference genome (GRCh38) using STAR.
3. Gene-level read counting using featureCounts.

## Analysis Workflow

The analyses are performed using the following steps:

1. Load the gene count matrix (`countdata.rds`).
2. Prepare sample metadata and create a DESeqDataSet object.
3. Estimate size factors and perform regularized log transformation (rlog).
4. Generate a heatmap of the top 2,000 most variable genes.
5. Perform GO Cellular Component (GO-CC) enrichment analysis.
6. Calculate log2 fold changes between the TGFB1_siHic-5 and TGFB1_siCNT groups.
7. Perform GSEA using Hallmark TGF-beta signaling, Hallmark EMT, and ECM-related GO Biological Process gene sets.

## Notes

The GSEA ranking was generated from log2 fold changes calculated using the mean normalized counts of the TGFB1_siHic-5 and TGFB1_siCNT groups.

The RNA-seq data were pooled, and the GSEA results are presented as directional enrichment analyses rather than statistical inference between biological replicates.

The GO-CC analysis selected genes showing an absolute difference greater than log2(1.5) in rlog-transformed expression values between the TGFB1_siHic-5 and TGFB1_siCNT groups.
